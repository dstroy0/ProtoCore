================================================================================
ESPRESSIF ESP32-S2: CRYPTOGRAPHIC ACCELERATOR REGISTER SPECIFICATION
================================================================================

---

1. AES CO-PROCESSOR REGISTER MAP (Base Address: 0x6003A000)

---

The S2 AES engine unifies data streams into specific APB register windows,
utilizing a dedicated Crypto-DMA pipeline.

| Offset | Register Name      | R/W | Field/Bit Configuration [Hardware Details]                              |
| ------ | ------------------ | --- | ----------------------------------------------------------------------- |
| 0x000  | AES_KEY_0_REG      | W   | [31:0] Key Word 0 (Total 8 sequential registers up to 0x01C)            |
| 0x020  | AES_TEXT_IN_0_REG  | W   | [31:0] Plaintext Input Word 0 (Total 4 sequential registers to 0x02C)   |
| 0x030  | AES_TEXT_OUT_0_REG | R   | [31:0] Ciphertext Output Word 0 (Total 4 sequential registers to 0x03C) |
| 0x040  | AES_MODE_REG       | R/W | : 0=Encrypt, 1=Decrypt                                                  |

       |                       |     | [2:1]: Key Size Selector (00=128-bit, 01=192-bit, 10=256-bit)

0x044 | AES_ENDIAN_REG | R/W | [5:0]: In-silicon byte/word swapping configuration for Key/In/Out
0x048 | AES_TRIGGER_REG | W |: Strobe high (1) to execute manual block cipher calculation
0x04C | AES_STATE_REG | R | [1:0]: State Machine Flags: 0=IDLE, 1=LOAD, 2=CALC, 3=DONE
0x054 | AES_DMA_IN_CTRL_REG | R/W |: Bit 0: 1=Route Crypto-DMA input channel directly to AES FIFO
0x058 | AES_DMA_OUT_CTRL_REG | R/W |: Bit 0: 1=Route Crypto-DMA output channel directly to AES FIFO

---

2. SHA SECURE HASH ENGINE (Base Address: 0x6003B000)

---

| Offset | Register Name       | R/W | Field/Bit Configuration [Hardware Details]                     |
| ------ | ------------------- | --- | -------------------------------------------------------------- |
| 0x000  | SHA_MODE_REG        | R/W | [2:0]: Hash Mode (1=SHA1, 2=SHA256, 3=SHA384, 4=SHA512)        |
| 0x004  | SHA_START_REG       | W   | : Pulse 1 to run calculation on initial message block          |
| 0x008  | SHA_CONTINUE_REG    | W   | : Pulse 1 to process subsequent block sequence data            |
| 0x00C  | SHA_BUSY_REG        | R   | : 1=Hash engine active, 0=Ready/Idle Saturated                 |
| 0x010  | SHA_H_0..15_REG     | R   | [31:0] Internal/Final Digest State (16 sequential registers)   |
| 0x050  | SHA_M_0..15_REG     | W   | [31:0] Raw Message Block Input space (16 sequential registers) |
| 0x090  | SHA_DMA_IN_CTRL_REG | R/W | : Bit 0: 1=Route Crypto-DMA input directly to SHA Block Buffer |

---

3. RSA / MULTI-PRECISION INTEGER (MPI) CO-PROCESSOR (Base Address: 0x6003C000)

---

| Offset | Register Name         | R/W | Field/Bit Configuration [Hardware Details]                      |
| ------ | --------------------- | --- | --------------------------------------------------------------- |
| 0x000  | RSA_SET_START_MODEXP  | W   | : Launch Montgomery Modular Exponentiation                      |
| 0x004  | RSA_SET_START_MODMULT | W   | : Launch Montgomery Modular Multiplication                      |
| 0x008  | RSA_SET_START_MULT    | W   | : Launch Large-Integer Matrix Multiplication (Normal)           |
| 0x00C  | RSA_QUERY_BUSY_REG    | R   | : 1=RSA execution active, 0=Idle/Complete                       |
| 0x010  | RSA_LENGTH_REG        | R/W | [5:0]: Array size bound register: ((WordCount) - 1)             |
| 0x014  | RSA_COMP_MODE_REG     | R/W | : 0=Standard core engine, 1=Accelerated Montgomery Core         |
| 0x800  | RSA_MEM_X_BASE        | R/W | Multiplicand Block Memory X array space (512 bytes / 4096 bits) |
| 0xA00  | RSA_MEM_Y_BASE        | R/W | Exponent / Multiplier Block Memory Y array space (512 bytes)    |
| 0xC00  | RSA_MEM_M_BASE        | R/W | Modulus Block Memory M array space (512 bytes)                  |
| 0xE00  | RSA_MEM_Z_BASE        | R/W | Calculated Output / Intermediate Matrix Z space (512 bytes)     |

4. ECC / ECDSA CORE ACCELERATOR (Base Address: 0x6003E000)

---

| Offset | Register Name | R/W | Field/Bit Configuration [Hardware Details]                 |
| ------ | ------------- | --- | ---------------------------------------------------------- |
| 0x000  | ECC_START_REG | W   | : Write 1 to launch internal hardware calculation sequence |
| 0x004  | ECC_BUSY_REG  | R   | : 1=Elliptic Curve engine active, 0=Pipeline open          |
| 0x008  | ECC_MODE_REG  | R/W | [2:0]: Curve Select (0=P-256, 1=P-192, 2=P-384, 3=P-521)   |

       |                       |     | [5:3]: Macro operation command code (Scalar Mult, Jacobian Check)

0x00C | ECC_INT_EN_REG | R/W |: Assert global interrupt flag upon completion
0x010 | ECC_INT_CLR_REG | W |: Clear completion status latch

---

5. DIGITAL SIGNATURE (DS) & HMAC CORE REGISTERS (Base Address: 0x6003D000)

---

| Offset                                                                           | Register Name      | R/W | Field/Bit Configuration [Hardware Details]                      |
| -------------------------------------------------------------------------------- | ------------------ | --- | --------------------------------------------------------------- |
| 0x000                                                                            | DS_START_REG       | W   | : Strobe 1 to begin hardware signature generation               |
| 0x004                                                                            | DS_BUSY_REG        | R   | : 1=DS peripheral internal operations active, 0=Ready           |
| 0x008                                                                            | DS_IV_0_REG        | W   | [31:0] Initialization Vector Word 0 (Total 4 words up to 0x014) |
| 0x100                                                                            | DS_M_MEM_BASE      | W   | Input message memory array base for RSA signatures (512 bytes)  |
| 0x200                                                                            | DS_Y_MEM_BASE      | R/W | Internal encrypted signature parameter block base (512 bytes)   |
| 0x300                                                                            | DS_X_MEM_BASE      | R   | Output signature computation result base (512 bytes)            |
| 0x400                                                                            | HMAC_SET_START_REG | W   | : Pulse 1 to begin HMAC hash key-derivation                     |
| 0x408                                                                            | HMAC_KEY_SEL_REG   | W   | [2:0]: Select unexposed eFuse key blocks (0-5) for hash         |
| 0x410                                                                            | HMAC_TEXT_IN_REG   | W   | [31:0] Stream data window directly for message hash             |
